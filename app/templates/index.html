The following endpoints can be tested using Postman or another API testing tool.

1. Organization Management

Method Endpoint Purpose
POST /organizations/ Create an organization
GET /organizations/ Retrieve all organizations
GET /organizations/<id> Retrieve an organization by ID
PUT /organizations/<id> Update an organization
DELETE /organizations/<id> Delete an organization

2. User Management

Method Endpoint Purpose
POST /users/ Create a user
GET /users/ Retrieve all users
GET /users/<id> Retrieve a user by ID
PUT /users/<id> Update a user
DELETE /users/<id> Delete a user

3. Document Management

Method Endpoint Purpose
POST /documents/upload Upload a document
GET /documents/ Retrieve all documents
GET /documents/<id> Retrieve a document by ID
GET /documents/search Search documents by filename
PUT /documents/<id>/replace Replace an existing document
GET /documents/<id>/download Download a document
GET /documents/<id>/view View a document in the browser
DELETE /documents/<id> Delete a document

4. Permission Management

Method Endpoint Purpose
POST /permissions/ Assign permissions to a user for a document
GET /permissions/ Retrieve all permission records
GET /permissions/<id> Retrieve a permission record by ID
PUT /permissions/<id> Update a permission record
DELETE /permissions/<id> Delete a permission record

5. Authentication

Method Endpoint Purpose
POST /auth/login Authenticate a user and generate an access token
