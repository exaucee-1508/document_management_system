API Documentation

The following endpoints are available for interacting with the Document Management System API.

Base URL:
https://document-management-system-uls2.onrender.com

1. Organization Endpoints

Method Endpoint Description
POST /organizations/ Create an organization
GET /organizations/ Get all organizations
GET /organizations/{org_id} Get one organization
PUT /organizations/{org_id} Update an organization
DELETE /organizations/{org_id} Delete an organization

2. User Endpoints

Method Endpoint Description
POST /users/ Create a user
GET /users/ Get all users
GET /users/{user_id} Get one user
PUT /users/{user_id} Update a user
DELETE /users/{user_id} Delete a user

3. Document Endpoints

Method Endpoint Description
POST /documents/upload Upload a document

How to Test the API

Use Postman or another API client to send GET, POST, PUT, and DELETE requests to the endpoints above.
